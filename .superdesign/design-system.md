# Webase System Monitor design system (telemetry, 2026-11-21)
Windows desktop utility. Angular + Bootstrap 5.3 + SCSS tokens. 13px base text, Segoe UI Variable / Segoe UI; numbers and table figures in Cascadia Mono / Consolas (`--font-mono`). One green accent (dark #3ddc97, light #08704b); amber (#e0b341 / #9a6700) only for the memory line and big memory bars. Dark canvas #0a0e13, panels #0f151c, strips #131c26, side nav #0c1116, hairline #1b2634, text #c9d4df, muted #8497ab. Light canvas #f3f5f8, panels #fff, strips #eef1f5, side nav #eceff4, hairline #dce2ea, text #1b2531, muted #566474. Radius: 4px controls, 6px panels, 8px dialogs. Flat panels, no shadows, no gradients. Panel and column labels are small uppercase with letter-spacing in the muted colour. Layout: top bar (brand, Ctrl+K field, theme switch) over a 168px side nav of 5 sections; the open section lists its pages under it. Status colours: danger #ff6b81 / #b4233c, ok #5fd38a / #107c10. Dense, calm, instrument-like.
